# 🏗️ موقع مؤسسة المدائن الحديثة للمقاولات والديكور - جازان

موقع إلكتروني متكامل، حديث، ومتجاوب (Responsive) مصمم خصيصاً لـ **مؤسسة المدائن الحديثة للمقاولات والديكور** في منطقة جازان بالمملكة العربية السعودية.

---

## 🌟 مميزات المشروع

- 🎨 **تصميم عصري وجذاب:** واجهات أنيقة تعتمد على ألوان متناسقة (أزرق ملكي داكن وذهبي عنبري) مع خطوط عربية حديثة (Cairo & Tajawal).
- 📱 **متجاوب 100% (Responsive):** متوافق مع كافة الأجهزة (الجوالات، التابلت، والشاشات الكبيرة) مع قائمة جانبية مخصصة للجوال.
- 🛠️ **الخدمات 4 الأساسية:**
  1. **ترميم وتشطيب:** للمباني والفلل والمؤسسات.
  2. **هناجر ومستودعات:** تصميم وتنفيذ الهياكل الحديدية والمخازن.
  3. **أعمال عظم:** بناء الفلل والعمائر والقواعد الخرسانية.
  4. **ديكورات:** الجبس بورد، بديل الرخام، بديل الخشب، والإضاءات الحديثة.
- 🖼️ **معرض أعمال تفاعلي:**
  - تصفية المشاريع بحسب الفئة (All, Skeleton, Hangars, Renovation, Decor).
  - نافذة عرض المكبرة (`Lightbox`) لمشاهدة تفاصيل الصور والتواصل بخصوص مشروع مماثل.
- 📞 **وسائل تواصل مباشرة:**
  - أزرار اتصال هاتفي مباشر فورية عند الضغط على الأرقام.
  - نافذة اختيار رقم الواتساب المناسب (إدارة المشاريع أو قسم الديكور).
  - زر واتساب عائم أسفل الشاشة.

## 🚀 كيفية تشغيل المشروع

### 1. التشغيل المباشر:
يمكنك فتح ملف `index.html` مباشرة عن طريق النقر المزدوج عليه لفي أي متصفح (Chrome, Edge, Firefox, Safari).

### 2. التشغيل عبر خادم محلي (Local Server):
إذا كنت تستخدم Node.js، يمكنك تشغيل خادم محلي عبر الأمر التالي:

```bash
npx http-server . -p 8080
```
ثم فتح الرابط التالي في المتصفح: [http://localhost:8080](http://localhost:8080)

## 🛠️ التقنيات المستخدمة

- **HTML5 & CSS3:** الهيكل العام والتنسيقات.
- **Tailwind CSS (CDN):** لبناء الواجهات السريعة والتجاوب مع الشاشات.
- **Font Awesome 6 (CDN):** الأيقونات الحديثة والرمزية.
- **Vanilla JavaScript (ES6+):** لإدارة التفاعلات بدون مكتبات ثقيلة خارجية.
- **Google Fonts:** خطوط Cairo و Tajawal العربية.
